# Revival pastor landing-page headline test

Keep the video, page body, form, CTA, traffic source, and audience unchanged. Only the hero headline and supporting sentence change. This isolates the message rather than testing a different page experience.

## Measurement

- Primary: completed Revival application.
- Secondary: application-button click and lead-form completion.
- Use an even VWO traffic split.
- Do not call a winner from click-through rate alone.
- Keep each visitor in the same variation on return visits.
